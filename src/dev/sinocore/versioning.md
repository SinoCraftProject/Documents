# 版本号规则

自1.1.0起，华夏核心更改了版本号规则。现在版本号不再包含MC版本。  
版本号格式为：`主版本号.次版本号.修订号[-预发布标签][+构建元数据]`。

其中：  
主版本号（Major）会在每次MC互不兼容的版本更新时增长；
次版本号（Minor）会在添加新功能或者API发生变更时增长。
主版本号和次版本号的增长**都会**产生破坏性变更（Breaking change）。

修订号（Patch）会在修复Bug时增长，且不会引入破坏性变更；
预发布标签和构建元数据是可选的，预发布标签用于标识测试版本或候选版本，目前使用`-SNAPSHOT`来表示上传到Maven服务器的每周构建；
构建元数据目前未在Maven工件的版本号中使用，但用于在Modrinth平台上标记模组加载器平台（`+fabric`和`+neoforge`）。
